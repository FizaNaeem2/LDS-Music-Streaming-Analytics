# Assignment 21 — Lyrical Content Analysis

This Power BI dashboard analyzes lyrical characteristics and their relationship with streaming performance.

## Visuals
- Share of explicit vs non-explicit lyrics
- Song category distribution by lyric length
- Distribution of swear-word counts in lyrics
- Evolution of explicit lyrics over time
- Top songs by streams in the lyrics-based analysis

## Analytical focus
The dashboard combines track metadata, lyrical indicators, song-category information, time, and streaming measures to explore how lyrical content differs across songs and how those characteristics relate to performance.

## Security / reproducibility
The public PBIX copy has its original live SSAS endpoint, database, and cube connection replaced with placeholders. To reconnect it, configure your own Analysis Services endpoint, database, and cube in Power BI.

The original course project file is intentionally kept private.
