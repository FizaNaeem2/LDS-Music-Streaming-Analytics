# Assignment 22 — Streaming and Song Category Trends

This Power BI dashboard analyzes how music releases and streaming performance evolve over time across song categories.

## Visuals
- Artist quantity-versus-performance scatter analysis
- Streaming growth over time by song category
- Song release trends over time by category
- Individual growth trends for Energetic/Emotional, Energetic/Party, Mellow/Bright, and Soft/Chill

## Analytical focus
The dashboard compares artist output with streaming performance and tracks long-term changes in releases and streams across the four song categories. It supports comparison of category growth, historical release patterns, and differences in streaming trajectories.

## Security / reproducibility
The public PBIX copy has its original live SSAS endpoint, database, and cube connection replaced with placeholders. To reconnect it, configure your own Analysis Services endpoint, database, and cube in Power BI.
