# Assignment 20 — Geographic Stream Distribution

This Power BI dashboard analyzes the geographic distribution of music streams by artist birthplace and song category.

## Visuals
- Global map of streams by artist birthplace
- Song-category breakdown across geographic locations
- Ranked birthplace-level stream totals

## Analytical focus
The dashboard connects the Artist geography dimension, Track song-category dimension, and streaming measures from the multidimensional model to show where different music profiles perform geographically.

## Security / reproducibility
The public PBIX copy has its original live SSAS server, database, and cube connection replaced with placeholders. To reconnect it, configure your own Analysis Services endpoint, database, and cube in Power BI.

The original course project file is intentionally kept private.
